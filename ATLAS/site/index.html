Interpretation limits

  • Enhancer labels are DHS/H3K27ac proxies. No ATAC or silencer models are included.
  • E021 has only 288 total positive training-set elements across all splits; its test set is small.
  • HepG2 and K562 retain explicitly permitted ENCODE ERROR audits.
  • Model agreement and held-out metrics are not independent biological validation.
  • This is a timestamped public snapshot, not a live Slurm monitor. Full atlas files are not bundled with this website.
